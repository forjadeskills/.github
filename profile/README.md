# 🔨 Forja de Skills

**Skills gratuitas e open source para o Claude Code — feitas para quem está começando.**

</div>

---

A **Forja de Skills** nasceu de uma ideia simples: as melhores ferramentas de IA pra programar não deviam ser privilégio de quem já é experiente. Aqui a gente forja **skills, plugins e automações para o [Claude Code](https://claude.com/claude-code)**, sempre **grátis, abertas e fáceis de instalar** — pensadas pro programador iniciante e pra quem está chegando agora no "vibe coding".

## O que você encontra aqui

- 🧩 **Plugins de um comando** — instala direto pelo `/plugin`, sem configuração.
- 🏠 **Privacidade primeiro** — quando dá, roda 100% na sua máquina.
- 🤫 **Pouco ruído, muito sinal** — ferramentas que ajudam sem encher o saco.
- 📖 **Tudo explicado em português**, em linguagem simples.

## Skills disponíveis

| Skill | O que faz | Instalar |
|-------|-----------|----------|
| [🧠 **Super-Memory**](https://github.com/forjadeskills/super-memory) | Memória automática e de baixo ruído: o Claude lembra do seu projeto entre sessões, sem você anotar nada. | `/plugin marketplace add forjadeskills/super-memory` |

> Mais skills saindo da forja em breve. ⚒️

## Como instalar uma skill

Dentro do Claude Code:

```
/plugin marketplace add forjadeskills/super-memory
/plugin install super-memory@super-memory
```

## Quer contribuir?

Toda skill aqui é **MIT** — use, estude, melhore e compartilhe. Issues e Pull Requests são muito bem-vindos. Se você está começando e quer ajudar, esse é um ótimo lugar pra dar seus primeiros passos no open source. 💜
